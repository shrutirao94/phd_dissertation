\section{Template Used for Analysing and Reporting Session Level Overviews}
\label{apx-sec-session-template}
Workshop X: [Title / Metadata]
State the title of the workshop and provide the name of the participating firm, number of participants, date, and duration of session.  

Aim / Focus (2–3 sentences)
State the specific exploration goal of the session.

Approach / Activities (2–3 sentences)
State the tasks undertaken by the participants in the session and everything that they enaged with.

Emergent Findings 
State the top four or five key outcomes of the session in a descriptive-neutral language.

Visual Data
Provide the key sketches and ideas shared by each group that symbolises the workshop’s focus.

Transition / Cumulative Link (2–3 sentences)
Explain how this informed the next workshop.
